# Conversation Mode (opt-in)

- Conversation Mode is OFF by default. Only when the user explicitly asks to enter Conversation
  Mode, read `CONVERSATION_MODE.md` beside this global `AGENTS.md` in the effective Codex home
  (normally `~/.codex`, or `%USERPROFILE%\.codex` on Windows), then follow it for this conversation. Use its blocking foreground CLI wait, not MCP
  mailbox continuations or periodic background polling; stay silent while waiting.
- Installing, reading, quoting, or discussing these instructions does not activate the mode.
- When the user asks to exit Conversation Mode or stop listening, disable it for this conversation.

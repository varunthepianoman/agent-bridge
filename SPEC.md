# Agent Bridge Product Specification

Status: implemented single-user core
Version: 0.3

The normative product specification is
[docs/plans/general-execution-engine.md](docs/plans/general-execution-engine.md). It defines the
product thesis, domain model, identity rules, delivery semantics, interfaces, API disposition,
deployment boundary, and acceptance criteria.

The only planned expansion is the explicitly separate
[shared-workspaces add-on](docs/plans/shared-workspaces.md). Workflows, agent organizations, roles,
coordinators, and capability-based execution are not part of the current product.
